# M04-S3 research: word-revisions-ai-sharing

Researched 2026-11-09. Same access limits as M01 (named search engines blocked; metrics UNMEASURED). SERP capture PENDING (R05). One lookup with the unspecified-provider web search tool, restricted to support.microsoft.com; pages used were fetched and read.

Reader question: which revision view and comments a shared document should represent. Parent M04 reports one tracked replacement and one comment. This support adds an approved change, a pending insertion, a pending deletion, hidden text, three named readings and a reviewed copy that matches the decided reading.

Sources read:
- Microsoft Support, "Track changes in Word" (training, page date 2026-09-25): Simple Markup, All Markup, No Markup (changes incorporated), Original (without tracked changes and comments); pending changes and comments remain in the document.
- Microsoft Support, "Accept or reject tracked changes in Word" (page date 2026-09-25): remove markup by accepting or rejecting before sharing; No Markup only hides changes temporarily; Review > Tracking, Accept All Changes and Reject All Changes; Document Inspector checks tracked changes, comments, hidden text and personal names in properties.

Product facts: DOCX conversion keeps inserted text, drops deleted text and comments, and keeps text formatted hidden (observed).

Boundary: the decision about which changes are approved belongs to the document owner; the article shows how to record it, not what to decide.
