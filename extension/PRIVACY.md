# LLMiser Chrome extension privacy

Version 0.2.0 — 24 October 2026. Operator: DevBehindYou.

The extension has one file Converter screen in a toolbar popup. It does not capture webpages or selected text, collect analytics, monitor browsing history or send chat messages. Page extraction and its libraries were removed in version 0.2.0.

Selecting or dropping files does not upload them. Clicking Convert files requests optional access to exactly `https://llmiser.devbehindyou.com` and `https://ppmbqgecdbrezxedyeur.supabase.co`. If granted, file metadata (filename, size, content type and profile) goes to LLMiser; bytes go directly to its private Supabase Storage using a signed URL. LLMiser's existing backends process those files and Markdown is downloaded to the popup. Requests omit cookies, reject redirects and validate signed storage links against the expected project/bucket/job. No backend secret or service-role key ships in the extension. Normal service/network logs, processing and the default 48-hour retention with documented administrative exceptions apply. See https://llmiser.devbehindyou.com/privacy.

The `storage` permission keeps one editable file draft and up to 20 recovery records in `chrome.storage.session`. A draft contains Markdown, filename, capture time and warnings. Recovery records contain only job ID, filename and upload/processing phase; no signed URL, access token, original file bytes or browsing URL is retained in these records. Job IDs allow retrieval of those jobs; keep your browser session private. Chrome session storage is cleared when Chrome closes or the extension is disabled, reloaded or updated, and Chrome may clear it independently. Old page-capture drafts are not restored in this file-only version.

Original File objects, files waiting to upload, and the full multi-file review queue live only in the open popup's memory. Chrome closes the popup when you click outside it. Keep it open during upload. Reopening can restore the latest Markdown draft and resume an uploaded job using its original ID without creating another upload. An upload interrupted before all bytes reached Storage may need the file selected again. Closing the popup stops client waiting; uploaded server jobs can still finish and normal retention applies. A recovery record is removed after the completed draft is saved. Clear removes local drafts, queue and recovery records and stops waiting; it does not cancel/delete server jobs or uploaded files.

AI detection checks only the active tab's URL, using exact HTTPS hostnames for ChatGPT, Claude and Gemini. Temporary `activeTab` and `scripting` permissions are used only to insert text into the AI composer when you click Paste. The extension does not read conversation history. Paste inserts the current Markdown as plain text into a visible, empty composer, without clicking Send, pressing Enter, calling an AI API or overwriting an existing draft. The AI website can access inserted text even before you send it, and its privacy policy applies. Changed or unsupported editors show an error; Copy is the fallback.

Copy writes the current text to your clipboard only when clicked. Download creates a local Markdown file. Clipboard managers, downloads and other apps follow their own policies/settings. Clear does not erase exported files, the clipboard or an AI composer draft.

All executable code ships in the extension. There are no remote scripts, all-sites host permissions, background page capture, side-panel permission or telemetry endpoints. Network connections are restricted to the two named conversion hosts. Source/contact: https://github.com/DevBehindYou/LLMiser. This is a development build; no Chrome Web Store approval or publication is implied.
