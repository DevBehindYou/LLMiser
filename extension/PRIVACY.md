# LLMiser Chrome extension privacy

Version 0.1.0 — 24 October 2026. Operator: DevBehindYou.

The extension has one Converter screen for files, webpage text and selected passages. It does not collect analytics, monitor browsing history, automatically capture pages or send chat messages.

Webpage and selection capture happens locally when requested. Chrome's temporary `activeTab` permission and `scripting` run bundled extraction code in the isolated extension world. `sidePanel` provides the Converter screen. `storage` keeps one editable Markdown draft in `chrome.storage.session`, Chrome's session memory: text, title or filename, source URL without query/fragment, capture time, scope and warnings. Closing Chrome, disabling, reloading or updating the extension clears this session storage. Chrome may also clear it independently. The queue and its original File objects are held only in the open panel's memory; they are not retained as history.

Selecting or dropping files does not upload them. Clicking Convert files requests optional access to exactly `https://llmiser.devbehindyou.com` and the existing storage project `https://ppmbqgecdbrezxedyeur.supabase.co`. If granted, file metadata (filename, size, content type and selected profile) goes to LLMiser, and file bytes go directly to private Supabase Storage using a short-lived signed URL. LLMiser's conversion backends process those files; Markdown is downloaded to the editor. No backend secret, service-role key or account cookie is included in the extension. Requests omit cookies, reject redirects and accept storage links only for the expected project/bucket/job. Normal service/network logging, processing and the web app's default 48-hour retention with administrative exceptions still apply. See https://llmiser.devbehindyou.com/privacy. This online file workflow is separate from local webpage capture.

Hidden content, scripts and form fields are excluded from capture. Visible private content on a page you explicitly capture can still appear in your draft. Review it before copying or sharing. Markdown links can contain the original webpage's URLs, including query parameters; source metadata omits query strings/fragments, but this is not a general secret-redaction tool. Embedded frames, shadow DOM, Chrome internal pages, the Web Store and built-in PDF viewers are not supported.

AI detection checks only the active tab's URL, with exact HTTPS host matches for ChatGPT, Claude and Gemini. It does not read conversation history. Clicking Paste inserts the current Markdown as plain text into the visible, empty composer on that AI site using temporary active-tab access. The site can access text inserted into its composer even before you send it; its privacy policy applies. The extension does not click Send, simulate Enter, call an AI API or overwrite a nonempty composer. Unsupported or changed editors give a visible error and a Copy fallback.

Copy writes the current text to your clipboard only when requested. Download creates a local Markdown file. Clipboard managers, exported files and any app you paste into follow their own settings/policies. Clear removes the local draft and queue and stops waiting for in-flight conversions. It does not cancel or delete server jobs, erase the clipboard, remove an AI composer draft or delete exported files. Uploaded jobs can finish after you clear or close the panel and follow normal server retention.

All executable code ships in the extension package. There are no remote scripts, broad host permissions for all websites or telemetry endpoints. The content security policy allows network connections only to the two named upload-service hosts. Contact and source: https://github.com/DevBehindYou/LLMiser. No Chrome Web Store publication or approval is implied by this development build.
